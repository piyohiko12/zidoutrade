# moomooAI Q013 バックテスト後の見直し記録

記録日: 2026-08-14
種別: サニタイズ済み要約（逐語録ではない）
対象: `RSI_AUTOPILOT_V1` の研究用shadow比較

この文書には口座、注文、残高、position、価格、銘柄、検証期間、個別取引、正確なperformance値、
cookieその他の秘密を含めません。正確なperformanceの根拠は、リポジトリ外のowner-only領域にある
固定済みレポートだけです。moomooAIへの質問は情報取得だけで、OpenD、口座、注文にはアクセスして
いません。

## 1. 質問へ渡した情報

探索的なローソク足代理バックテストについて、口座・注文・残高等を除いた固定済みレポートの集計を
moomooAIへ伝えました。数値、結果の方向、取引内訳は公開リポジトリへ再掲しません。公開側で固定するのは、
評価が`EXPLORATORY_ONLY`であり、実約定、ユーザー選択、sealed OOSの証明ではないという証拠範囲だけです。

既存のRSI中心、long-only、ユーザー選択、確定RTH 15分足、先読み禁止、費用込み評価を維持し、
過学習を避けるため、変更候補を独立した原子的gateとして提示するよう求めました。利益保証、勝率保証、
REAL注文、新規契約、課金、権限追加は求めていません。

## 2. 回答の信頼性確認

moomooAIは、ATR比率、RSI条件、出来高、時間帯などを同時に変更する複数案を提示しました。一方、回答内の
performance表には、入力データのbar count等を取引数や損益と取り違えたとみられる値が含まれていました。
その表は外部の固定済みレポートと整合せず、再計算可能な根拠も示されていません。

したがって、次を採用しません。

- moomooAIが生成したperformance値、勝率、利益改善幅
- 複数条件を一度に変更する案
- 同じ履歴の結果を見ながら最良条件を選ぶこと
- 回答だけを根拠にproduction条件を変更すること

moomooAIは仮説の情報源であり、計算済みレポートや独立検証の代わりではありません。

## 3. 取り入れる原子的な研究gate

回答を順に点検し、先読みをせず、既存入力だけで決定論的に計算でき、単独比較できる最初の候補だけを
研究variantとして固定します。

| 項目 | 固定内容 |
|---|---|
| research-only ID | `RSI_AUTOPILOT_V1_Q013_ATR_CAP_0050_SHADOW` |
| 入力 | 最新の確定済みQFQ・RTH 15分足と、その時点までの同じ系列 |
| 指標 | Wilder ATR(14) |
| 式 | `latest_atr_qfq / latest_close_qfq` |
| PASS | 有限かつ正の値で、比率が`0.0050`以下（exact境界を含む） |
| WAIT | 比率が`0.0050`を超える、または必要本数不足、欠損、非有限値、0以下のclose/ATR |
| 動作 | backtest・将来SHADOW比較の固定候補。注文は0件 |

このgateは「直近の通常の15分値動きが終値の0.50%を超える場面では、新規買い仮説を見送る」という
研究上の上限です。0.50%が利益を増やす、損失を一定以内に収める、または最適値であることを意味しません。
entry時の1.5 ATR stop、RSI条件、Q012 gate、ユーザー選択、risk sizing、退出条件は変更しません。現releaseで
実装済みなのは探索的backtest variantと説明表示だけで、prospective paired-shadow recorderは未接続です。

## 4. productionへ採用しない理由

同じ履歴標本を見た後に追加したため、このvariantを同じ標本へ再適用した結果は
`IN_SAMPLE_POST_HOC`かつ`EXPLORATORY_ONLY`です。結果が良くても悪くても、production採用、threshold調整、
注文停止解除の根拠にはしません。現行`RSI_AUTOPILOT_V1`、production判断、runner/broker双方の無条件
注文hard stopは不変です。

## 5. 次の検証

recorder実装・独立監査後に、変更前controlとQ013 variantを同じ将来セッション、同じユーザー選択銘柄、
同じ確定足、同じ費用モデルで注文0のpaired shadowとして並走させます。比較前にID、式、境界、欠損時
`WAIT`を固定し、途中でthresholdを変更しません。

候補版の完結往復が150件に達するまでをStage 1、その後の50件を独立したStage 2として一度だけ評価します。
途中の`WAIT`、no-fill、controlだけが行った取引も除外せず、Stage 1通過後に条件を変更しません。変更した
場合は新しいversionとして0件からやり直します。

主指標は同じ固定期間の費用控除後terminal return差です。200件合算の差が正、候補版単体も正、独立した
Stage 2だけでも差が正であり、最大drawdownと最大単発損失が悪化せず、safety/data violationが0件である
ことをすべて要求します。完結取引数、profit factor、平均損益、stop退出、signal通過率、欠損による`WAIT`は
副指標であり、主指標の不合格を救済しません。十分な将来標本と独立確認がそろうまで`RESEARCH_ONLY`の
ままです。利益改善だけでなく、取引数が過度に減ることや特定の値動き局面を取り逃す不利益も確認します。

## 6. 安全上の限界

ATRは過去の値動きの尺度であり、将来のgap、slippage、急変、取引停止、通信・broker障害を予測したり、
損失上限を保証したりしません。shadow比較は発注せず、SIMULATEやREALの運用成績を証明しません。
Q013の表示が`PASS`でも注文経路は有効になりません。
